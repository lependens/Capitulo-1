# Hitos del proyecto SIAR / ET₀

Registro **append-only** de decisiones y resultados materiales. El estado vigente se consulta en [PROJECT_STATUS](PROJECT_STATUS.md) y los próximos gates en [ROADMAP](ROADMAP.md).

## Política del registro

- Añadir nuevas entradas al final; no reescribir ni borrar hitos previos para adaptarlos al presente. Un estado posterior no modifica retrospectivamente un resultado demostrado.
- Una corrección se registra como nueva entrada que identifica la anterior y explica qué se corrige.
- Incluir fecha, hito, resultado, PR/SHA cuando exista y significado para el proyecto.
- Registrar cambios de arquitectura, contratos demostrados, validaciones materiales y transiciones de etapa; no cada intento LIVE ni errores transitorios.
- Para una PR, la fecha es la de fusión. Para un hito operativo sin PR propia, es la fecha de constancia documental; no se atribuye una hora o fecha de ejecución no demostrada.
- No incluir secretos, datos raw, snapshots ficticios ni resultados aún pendientes. Este registro no sustituye la evidencia de ejecución.
