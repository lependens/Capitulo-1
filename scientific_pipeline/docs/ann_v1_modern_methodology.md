# ANN-V1-MODERN-ET0: frozen experiment contract

The frozen machine-readable protocol is `experiments/ann-v1-modern-et0.json`. It is anchored to Dataset Observational v1 (SHA256 `0ddb10941710f6d3a945eae94fe6b9eca36ae4c12f28203e2364862920a49bbb`) and ML rolling protocol (SHA256 `45f1c4f3ed20bb70dc3b1ca06a8e23ec14f95aae6b60f574e44a8a261cc07048`). The target is `PM_FAO56_V1`, an internally calculated estimate, not independent observed evapotranspiration. This experiment tests emulation of that calculation.

The five input families and nine primary stations are inherited from the ML protocol. Features include latitude, altitude, Ra and cyclic day-of-year components where specified. The target, EtPMon, other baseline outputs, residuals, station identifiers and TEST-derived information are excluded as predictors. Missing meteorological inputs make only the affected feature family ineligible.

DEVELOPMENT is 2004-2020. Four expanding-window folds train through 2009, 2012, 2015 and 2018 and validate on the subsequent disjoint periods through 2020. TEST 2021-2025 has `retrospective_locked` status. TEST was used in earlier ML research, so it is not a prospective untouched dataset; ANN architecture, training rules and champion are nevertheless fixed without ANN TEST inspection. Independent validation on 2026+ remains future work.

The candidate budget is 3 fixed ReLU architectures (one, two or three hidden layers) by 5 feature families, each with three fixed seeds. Adam, L2 penalty, learning rate and batch size are fixed in the protocol. Dropout is omitted because this implementation uses scikit-learn MLPRegressor, whose documented regularization control is L2. No seed is selected post hoc: predictions from all three seeds are averaged. The predeclared primary score is the eligible-n-weighted mean of the four outer-fold RMSE values on a common five-family cohort. Dispersion, input count and parameter count break ties as declared in the protocol.

For each fold, StandardScaler is fitted only on TRAIN. The last 15% of distinct TRAIN dates serve as an inner chronological validation set to choose epochs, with patience and maximum epochs fixed. The fold model is then retrained from initialization on the entire fold TRAIN for the selected number of epochs. The outer validation period never controls early stopping. After DEVELOPMENT selects one architecture per family and a champion, final models are fitted on all DEVELOPMENT rows; the per-seed epoch count is the median of that seed's four fold epochs. The model bundle, selection and output hashes are frozen before TEST access. TEST is evaluated once with those weights. TEST-best is descriptive only.

The main comparison is with the published HGB FULL model on exactly paired station-date rows, using the same PM target and predictive R2 definition. Own-family and common ANN cohorts are reported separately. Results are grouped by station, year, month, climatic season and station-year. The published HGB prediction file must pass its manifest hash check. Negative or nonfinite ANN predictions are diagnostic findings, never silently clipped.

The implementation uses `MLPRegressor.partial_fit` for explicit one-epoch updates, consistent with [scikit-learn 1.9.1 documentation](https://scikit-learn.org/stable/modules/generated/sklearn.neural_network.MLPRegressor.html). The code keeps separate DEVELOPMENT and TEST commands; the TEST command verifies frozen protocol, selected configuration, bundle and hashes before recording TEST opening. Outputs are append-only. Run manifests retain dataset, protocol, AHC, pipeline, environment and output identities. Scientific publication requires ingestion receipt and remote preservation verification.

## Reproduction

Run `python -m siar_science.ann_campaign develop --help`, then, after DEVELOPMENT is frozen, `python -m siar_science.ann_evaluate --help`. Use an output directory that does not already exist. Run commands from a merged pipeline commit; do not use the legacy ANN scripts.
